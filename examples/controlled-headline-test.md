# Controlled headline comparison: planning example

Fictional desk-organiser example, no measured performance. Six separate cable loops is the only
supplied feature. The two headlines are candidates, not claimed winners.

| Field | Draft decision |
|---|---|
| Question | Which of two truthful headline appeals acquires customers more economically? |
| Control | A: Six cables, each with a place. Preserve the actual existing ad as the control when supplied. |
| Variant | B: Give every charging cable a home. |
| Design | Planned single-factor headline comparison, subject to the actual allocation method. |
| Constants | Same inspected product photo, supporting copy, price/terms, CTA, destination and eligible audience. |
| Allocation | Unspecified; choose and record a suitable assignment method before claiming a causal test. Ordinary uneven platform delivery is observational. |
| Main outcome | Acquisition cost divided by new customers, using the same attribution definition and completed observation window. |
| Diagnostics | Click-to-view loss, purchase conversion, variable contribution, returns and tracking integrity. |
| Exposure | Budget, baseline conversion rate and meaningful effect are not supplied. Obtain them for a justified volume/duration plan. |
| Decision | Keep the control unless evidence supports a commercially material improvement; allow inconclusive. Specify the evidence rule before launch. |
| Stops | Approved spend ceiling, broken checkout/tracking, unavailable product or other material commercial failure. |
| Limits | No sales, randomisation or improvement established by this draft. Scaling needs a separate read. |

If B requires a different photo or body to make sense, relabel the design as a package comparison.
Record the control and variant appeals and all outcomes within the existing test entry. Creating
this plan does not launch ads or update a brand's controlled test register.
