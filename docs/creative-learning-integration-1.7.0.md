# Creative learning integration: 1.7.0

Prepared 16 September 2026 at the owner's request to consolidate the reviewed methods, complete
the final checks and prepare for GitHub. Pushing and release publication are separate actions.

## What changes

The agent now briefs photographic cohesion, exact reference roles, material accuracy, deliberate
typography and a preserve/change record before image revisions. Full regeneration honours the
chosen scene and production instruction. Product identity is distinct from its source pose.

Format recommendations name established structures and give three executions within each selected
format. Hooks coordinate visual, speech and screen headline, with a useful next beat. The headline
is reviewed separately from captions and approved speech survives headline-only revisions.
The framework menu extends this through connected primary text and a complete filmable script.

The core remains brand-neutral. Selected brand context supplies ratio defaults, creative voice,
visual preferences, naming and library layout. Owner-specific examples, product facts, offer values,
measurement definitions and private design destinations travel in the separate brand bundle.
The repository's public visibility was verified during preparation.

## Conflicts resolved deliberately

- The current request overrides archived training schedules. No remaining reference quota blocks
  creation or release.
- The focused review package excluded research connectors and evaluators from ordinary creative
  work. Their optional existing capabilities remain available when requested; no extra judge or
  automatic rewrite loop is introduced into production.
- A request for full regeneration controls production. The older cutout fallback cannot silently
  override it. Exact typography/wordmark finishing is described accurately.
- Stored brand ratio preferences now override generic square/Story fallback dimensions.
- An execution's red highlight, pale background, brain or seal is not a mandatory brand template.
- Owner-approved appearance and wording are distinct from factual substantiation, actual campaign
  outcomes, fresh-host repeatability and launch approval.
- Historical offer values and exact metric configurations remain dated brand records.

## Packaging corrections

The craft bundle now reads the renamed deliverables section and includes the format library used
by the new contract. A worked format-options example is supplied. Generated entrypoints and bundles
are rebuilt from their maintained sources. Version declarations and user-facing routes are aligned.

The image edition keeps the full operative image core and the new art-direction and format
instructions within its existing 90,000-byte limit. It omits the duplicate general prompt,
video-only format material, dated connector setup notes, bibliography and duplicate checklists.
The maintained reference files and full knowledge edition retain that material. The craft eval
and bundle now load the same sections declared by SKILL.md, including format recommendations.

Validation results and the retained independent forward-test are documented in
