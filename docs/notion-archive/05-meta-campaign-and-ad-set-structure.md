# Account structure

Create one campaign per product, per region. The account develops in two stages: creative testing first, then scaling.

# Stage 1: Creative-testing campaign

## Campaign model

- Objective: learn what the market responds to
- Budget type: ABO
- One campaign per product per region
- One concept test per ad set
- Four ads per ad set
- One ad for each core awareness level

## Why ABO

ABO protects a defined budget for every concept test. It prevents Meta from concentrating all campaign spend into an early favourite before each concept has had enough opportunity to produce directional learning.

The aim is not merely to find one efficient ad. The aim is to prove or disprove hypotheses about the market, message and execution so the account can scale with greater confidence.

## Budget

- Absolute floor: $50 per ad set per day
- Preferred starting point: approximately $100 per ad set per day
- Higher budgets: set from the product price, target CAC, available capital and account context

The floor is a general operating minimum, not a universal formula. Larger launches may intentionally use substantially more budget.

## Observation window

Leave the initial test live for five full days before the planned review.

Avoid premature intervention unless there is a clear operational failure, broken destination, policy problem or unacceptable commercial risk.

## Broad-test principle

The first test intentionally changes awareness, format and destination together. These are large swings designed to discover useful territory. Results identify the strongest complete execution and create hypotheses. They do not prove that one isolated variable caused the result.

# Stage 2: Scaling campaign

## Campaign model

- Purpose: distribute budget efficiently across proven winners
- Budget type: CBO
- Created only when useful winners exist
- Contains the strongest ads graduated from testing
- Budget is controlled at campaign level

Winners move into scaling using their existing Post ID so performance history and identity remain traceable. The full ad name ends with the real Post ID.

> ABO creates the learning. CBO converts that learning into scale.

# Relationship between stages

1. Test a CONTST batch in ABO.
2. Observe for five days.
3. Diagnose business, funnel and creative signals.
4. Keep, iterate, stop or graduate.
5. Move proven winners into the CBO scaling campaign.
6. Continue building ITR batches from evidence.

The detailed verdict rules live in Testing, Measurement and Decisions.
