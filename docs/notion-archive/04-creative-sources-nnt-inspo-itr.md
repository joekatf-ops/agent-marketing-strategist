# Purpose

Every CONTST batch receives a source classification. The source describes where the test came from, not the awareness level or media type.

# NNT: Net-New Test

A genuinely new Who x Problem hypothesis.

Use NNT to:

- Explore a new audience or situation
- Explore a new primary problem
- Test a large strategic hypothesis
- Open new creative territory when existing concepts are weak

A new hook, format or messaging route against an existing coordinate is not automatically an NNT.

# INSPO: Inspiration

A pattern modelled from competitor creative, another category or another industry.

INSPO can borrow:

- Format or production structure
- Hook architecture
- Demonstration pattern
- Narrative sequence
- Proof presentation
- Offer presentation
- Messaging route

INSPO must not copy:

- Brand identity
- Proprietary claims
- Customer language without adaptation
- Visual assets or scripts
- Competitor names inside the reusable core system

The aim is to understand why the external pattern works and adapt that principle to the selected Who x Problem coordinate.

# ITR: Iteration

An evidence-led follow-up to an existing test.

Use ITR when previous data reveals:

- A winning execution worth expanding
- A promising concept with a diagnosed weakness
- Strong attention but weak conversion
- Strong conversion from a weak hook
- A useful format, proof style or message that needs refinement
- A page-congruence problem that can be repaired

ITR may change:

- Messaging route
- Hook
- Format
- Proof
- Visual execution
- Creator
- Offer presentation
- Destination

The underlying Who x Problem coordinate remains fixed. If either pillar changes, create a new coordinate.

# Test-batch rule

Each new NNT, INSPO or ITR launch receives a new sequential CONTST### identifier. This removes the need for a version suffix and preserves a clean history of what was launched.

# Maturity principle

Early-stage accounts need more NNT and INSPO because the message territory is still unknown. ITR grows only after meaningful signals exist. The mix should follow the maturity of the evidence rather than a permanent percentage.
