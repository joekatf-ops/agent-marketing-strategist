# Format is an execution vehicle

A format is selected after the Who, Problem and awareness job are clear. It is never part of the concept coordinate.

Distinguish:

- Media type: video, image or carousel
- Execution format: UGC, VSL, founder, demonstration, testimonial, comparison, static or another defined structure

# Core media types

## Video

Useful for:

- Demonstration
- Story
- Mechanism explanation
- Comparison
- Founder or expert communication
- Testimonials and social proof

## Static image

Useful for:

- Direct hooks
- Visual contrast
- Proof and offers
- Diagrams and annotations
- Rapid message validation

## Carousel

Useful for:

- Sequences
- Multiple proof points
- Steps
- Structured comparisons
- Before-and-after logic

# Initial diversity rule

The four launch ads should be meaningfully different. Do not produce four cosmetic variations of the same execution.

Diversity can come from:

- Awareness entry point
- Messaging route
- Format
- Creator or authority source
- Proof type
- Visual construction
- Destination

# Hook development

The opening earns the next moment of attention.

Build one coherent opening from:

1. Visual hook
2. Spoken or written hook
3. On-screen anchor

All three should communicate the same idea. The body must deliver what the hook promises.

# Production brief requirements

Every production brief should include:

- CONTST test ID
- Source: NNT, INSPO or ITR
- Who
- Primary Problem
- Awareness level
- Messaging route
- Primary hook
- Media type and format
- Proof and claims required
- Destination
- CTA
- Required people, assets and location
- Final ad name ending in POSTIDXXX

# Quality guardrails

- Make every ad independently understandable.
- Demonstrate rather than assert whenever possible.
- Keep claims within approved evidence.
- Match the destination to the promise.
- Use format to strengthen the message, not to decorate it.
- Avoid minor pre-test variations that do not create meaningful learning.
