## Release boundaries

Universal methods and their examples belong in this public repository. Private brand facts, offer
history, approved wording, asset paths, design-file destinations and project records are maintained
in the separate private pack. The existing frozen checkpoint is unchanged. The prepared package
must be installed or uploaded with the chosen brand context on a new host; it does not synchronise
other accounts or retrain the underlying model. No ads or campaigns were published by these checks.
