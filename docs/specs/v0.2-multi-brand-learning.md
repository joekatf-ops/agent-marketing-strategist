# Marketing Strategist v0.2 Specification

## Goal

Turn the existing methodology library into one portable DTC Meta strategist that loads a
separate brand folder for every engagement, researches from evidence, creates production-ready
assets, and becomes more accurate through approved human revisions.

## Locked decisions

1. The universal skill contains Joe's direct-response method and no brand-specific facts.
2. A connected brand folder is the canonical source for brand context, evidence, creative and
   retained learning.
3. One brand folder supports multiple markets, products, SKUs and offers.
4. Brand learning never transfers to another brand automatically.
5. A brand learning may enter the universal method only through explicit human promotion.
6. The agent may write drafts, evidence and learning events to a writable brand folder.
7. Permanent brand rules require the promotion policy in this specification.
8. Firecrawl is the preferred website-crawling capability.
9. The agent checks the brand website for changes whenever the brand folder is opened, crawls
   changed pages, runs a full crawl every seven days, and forces a refresh before major research,
   concept batches or launches.
10. Site snapshots and change logs are retained. Approved claims and rules are never silently
    overwritten by website changes.
11. Existing brand reviews are stored in the brand folder. If a new brand has no customer
    evidence, the agent researches competitor sites, competitor reviews and public communities
    and labels those findings as market evidence.
12. Connectors are documented capability adapters. The skill never assumes a connector is live
    until a preflight check succeeds.
13. First-class runtime guides cover Codex, Claude, Claude Code, ChatGPT, Gemini, Grok and Grok
    Agents.
14. Live Meta reporting is deferred. Manual performance inputs remain supported.
15. A hook is a package containing format, visual opening, spoken opening and on-screen anchor.
16. The default selected video execution receives six hooks across at least four hook formats.
17. The default selected ad receives two lead strategies in short, medium and long primary text,
    five headlines, two descriptions and one selected CTA.
18. Awareness coverage is checked across the creative portfolio rather than forced into exactly
    four ads for every concept. Most-aware is a first-class state.
19. Human revisions create learning events. The agent does not blindly learn every edit.
20. Connected-folder runtimes write learning in place. Upload-only runtimes return a learning
    patch for the canonical folder.

## Brand folder responsibilities

The folder stores a manifest, brand context, product truth, offer economics, approved claims,
proof, research snapshots, an evidence ledger, customer intelligence, concepts, creative,
human-approved revisions and learning.

Raw evidence remains distinct from synthesis. Brand website copy is a brand assertion, not
customer proof. Competitor-customer language is market evidence, not proof about the brand's own
customers.

## Learning policy

Every learning event records its brand, market, product, source asset, before and after text,
reason, scope, classification, status, confidence, author and timestamp.

- A factual or compliance correction becomes a hard rule only after explicit approval.
- A voice rule becomes permanent after explicit approval.
- A preference needs three consistent approved signals before it is proposed as a brand rule.
- An execution-specific edit remains attached to that execution.
- A personal editor preference is not a brand rule.
- Rejected, accidental and draft edits are not learned.
- Rules are superseded with history. They are never silently deleted.

## Connector contract

Each connector guide states its capability, supported workflows, secret names, setup by runtime,
preflight test, expected outputs, fallback and the limitation created when it is unavailable.
Secrets never live in the brand folder or skill repository.

## Required outputs

The skill adds contracts for brand readiness, hook batches and learning updates. Existing
contracts are revised for portfolio-level awareness coverage, multiple copy lengths, manual
performance input and evidence confidence.

## Reliability

Deterministic scripts initialise a brand folder, append validated learning events, build an
uploadable brand bundle and validate package integrity. Tests cover normal behaviour and failure
conditions. Frozen examples demonstrate the required output shape.

## Out of scope for v0.2

- Live Meta Ads API reporting
- Campaign creation or publishing
- Budget mutations
- Automatic cross-brand learning
- Automatic promotion of permanent brand rules
